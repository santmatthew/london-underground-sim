# Regenerating the large assets

Git holds code, data, tools and fonts only. Everything else is generated by the pipelines below and is git-ignored:
`assets/textures/`, `assets/people/`, `assets/models/`, `assets/audio/` (plus `build/` scratch and `.godot/`).

Prerequisites: Python 3.12, `ffmpeg`, Blender 5.2 (snap; it can only see non-hidden dirs of $HOME, so keep the project under $HOME),
Godot 4.7, internet access. Create the Python env once: `python3 -m venv build/venv && build/venv/bin/pip install numpy pillow scipy piper-tts`.

| Asset | Command | Notes |
|-------|---------|-------|
| Network data | `python3 tools/fetch_tfl.py && python3 tools/build_network.py` | TfL Unified API -> `data/network.json` (committed) |
| PBR textures | `python3 tools/fetch_textures.py && build/venv/bin/python tools/gen_textures.py` | ambientCG CC0 + procedural metro tiles, sleepers, grime |
| MakeHuman asset packs | `tools/fetch_mpfb_assets.sh` | needs the MPFB extension: download `add-on-mpfb-v2.0.17.zip` from extensions.blender.org and `blender -b --factory-startup --command extension install-file -r user_default --enable mpfb-2.0.17.zip` |
| People (36 characters + 25 mocap clips) | `tools/blender/people/rebuild_all.sh` | CMU BVH clips are fetched from `una-dinosauria/cmu-mocap` into `build/mocap` |
| Trains | `blender -b --factory-startup -P tools/blender/train/make_train.py -- deep_mid deep_cab ss_mid ss_cab` | textures: `tools/blender/train/make_textures.py` |
| Station props + fictional posters | `blender -b --factory-startup -P tools/blender/props/make_props.py` | see `tools/blender/props/make_docs.py` |
| Station character textures | `python3 tools/gen_textures.py metro_sq_grey && python3 tools/gen_char_textures.py` then `python3 tools/fix_texture_imports.py` | name friezes for every station, "Way out" patches, tile lettering, Victoria recess motifs (`assets/textures/char`, data in `data/station_character.json`); needs the URW C059 font (`fonts-urw-base35`) |
| Floors, halls, Oxford tile, street | `python3 tools/gen_textures.py halls`, `... floors`, `... oxford`, `python3 tools/gen_street.py` | hall finishes (brick, floor tiles, metal ceiling), lozenge/diamond/slab floors, the Oxford Circus interlace, the three street views behind the way-out doors |
| Audio (speech, ambience, SFX) | `build/venv/bin/python tools/audio/make_audio.py` | ~20 min for the 1300+ Piper speech clips |
| Godot import | `godot --headless --path . --import` | run again after adding assets (twice if it complains) |

`tools/setup_assets.sh` runs the cheap steps; the long ones are listed but not run automatically.

## Reference photographs
`tools/fetch_refs.py`, `tools/fetch_cat.py`, `tools/fetch_q.py`, `tools/fetch_lines_refs.py` download openly licensed photos from
Wikimedia Commons into `build/refs/` (never committed, never shipped) to compare renders against real stations and signage.

## Testing helpers
- `tools/gtest.sh <test>` runs `tests/<test>.gd` headless (`GTEST_ENGINE_ARGS="--fixed-fps 60"` for fast simulation).
- `tools/shot.sh <scene>` renders under xvfb (no window on your desktop) and prints errors.
- `tests/walkbot_test.gd`, `tests/walk_test.gd`: physical and ray-cast audits that every planned route has floor and no blockers.
- `tests/bot_test.gd`: the autopilot plays a whole journey (`--seed=N`, `--multi=3`, or `--start= --dest= --hour=`).
- `tools/record_video.sh out.mp4 [seed] [fps] [WxH] [game args]`: records an autopilot journey (Godot Movie Maker + ffmpeg).
